# Reviewed ACP edits across Java files

Open **Rocketbrain: Review an ACP Multi-File Edit** in a trusted local workspace. Select two to four saved Java files in one workspace folder, choose a configured local ACP v1 agent, and describe the coordinated edit. Review the executable, literal arguments, SHA-256 fingerprint and precise request text before sending them to the agent. A local `stdio` program is listed in `rocketbrain.acp.agents`. For OpenCode, set `rocketbrain.acp.workspaceEditOpenCodePath` and the numeric loopback endpoint and model in `rocketbrain.localCodeModel`. [OpenCode ACP documentation](https://opencode.ai/docs/cli/acp)

Open each file's diff in VS Code. **Apply Reviewed Workspace Edits** asks for approval of the exact set of replacements. Rocketbrain checks every saved file's bytes and editor version again, then submits one text-only `WorkspaceEdit`. Apply changes to the editor buffers and save them with normal VS Code controls. An early source modification or a stale review prevents the batch from applying.

The review accepts one uniquely identified fragment per selected file. Source inputs are limited to 3 KiB each and 8 KiB in total. This workflow edits existing Java source and uses transient review state. The local peer receives the explicitly selected text in a private working directory. Rocketbrain grants no editor file or terminal API and passes no MCP servers. The OpenCode adapter disables tools and sends the exact approved prompt once to the configured loopback model, using JSON Schema output. Other trusted `stdio` programs run under the current operating-system account and control their own backend.
