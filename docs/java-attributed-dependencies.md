# Compiler-attributed Java dependencies

Run **Rocketbrain: Inspect Java Dependencies** and choose **Javac attributed references** for a workspace folder, or browse to a project directory inside the workspace. Open **Javac project references** or **Javac package references** to inspect edges and cycle groups. Each edge can open its source reference and bound type declaration. A project edge also shows matching direct Maven or Gradle declarations and any local project outputs observed by the imported Java model. [Javac source and symbol API](https://docs.oracle.com/en/java/javase/25/docs/api/jdk.compiler/com/sun/source/util/Trees.html)

The source packet follows actual type and member uses, including fully qualified code without imports, overloads, enum constants, field reads, constructor calls and method references. An unused import remains visible in the declared-import layer. It adds no attributed usage edge.

The attributed layers use one compiler packet of saved production classpath sources, with a shared set of observed local archives from participating imported projects. They use the independent JDK's Java 25 language level and describe those compiler bindings. Maven and Gradle apply their own reactor, profile, classpath and task rules. For example, a packet can bind both sides of a source cycle while Maven refuses to build the cyclic reactor. **Inspection details** shows the attribution result, including compiler errors. [Maven reactor documentation](https://maven.apache.org/guides/mini/guide-multiple-modules.html), [Gradle multi-project builds](https://docs.gradle.org/current/userguide/multi_project_builds.html)

Named JPMS directives and compiled references remain in their existing layers. The new mode covers ordinary production Java source in one selected local directory. Test and generated source sets, arbitrary build execution, mixed language targets, reflection, dynamic build declarations and dependency-only archives as graph nodes are outside its scope. Refresh the report after editing a reviewed source or build descriptor.
