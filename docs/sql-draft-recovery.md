# SQL 콘솔 초안 복원

폴더를 연 신뢰된 워크스페이스에서 Rocketbrain SQL 콘솔을 열고 **Track SQL Console as Draft**를 실행합니다. 이름을 정하면 콘솔의 쿼리와 선택 영역이 편집 중에도 해당 워크스페이스의 로컬 VS Code 저장소에 갱신됩니다. 보관할 내용에서 비밀번호나 토큰을 먼저 제거하세요.

**Save SQL Draft Checkpoint**로 현재 내용을 즉시 보관합니다. VS Code를 다시 열거나 콘솔을 닫은 뒤 **Restore SQL Draft**에서 작업을 이어갑니다. 복원한 편집기에서도 초안이 계속 갱신됩니다. **Remove SQL Draft**로 보관본을 지울 수 있습니다.

**Browse SQL Draft Checkpoints**에서 명시적으로 저장한 버전과 최신 초안의 차이를 엽니다. **Restore as Copy**는 해당 버전을 새 오프라인 초안으로 열어 최신 원문을 보존합니다. 같은 버전을 다시 저장하면 기존 체크포인트를 재사용합니다. 초안마다 최신 체크포인트 8개와 워크스페이스 전체 체크포인트 SQL 2 MiB를 보관합니다. 초안을 제거하면 해당 체크포인트도 지워집니다.

복원한 편집기는 오프라인 상태로 열립니다. 실행하려면 SQL을 검토하고 의도한 연결의 콘솔로 복사합니다. 복원 대상은 편집기 텍스트와 선택 영역입니다. 연결, 결과, 그리드 변경 초안 및 서버 트랜잭션은 별도 수명주기를 사용합니다.

초안은 워크스페이스당 최대 16개, 각 128 KiB, 전체 텍스트 1 MiB까지 보관합니다. 한도에 달하면 이전 보관본을 유지하며 **Save SQL Draft Checkpoint**에서 공간을 확보하라는 메시지를 보여줍니다.

## 읽기 전용 결과 보관

**Save Query Result Snapshot**에서 완료된 조회 결과를 선택하고 이름을 정합니다. 선택한 결과의 행과 열은 해당 워크스페이스의 로컬 저장소에 남습니다. **Open Saved Query Result**는 연결 없이 결과 그리드를 열고, **Remove Saved Query Result**는 저장된 스냅샷을 지웁니다.

스냅샷당 최대 500행·256열·1 MiB를 보관합니다. 워크스페이스 한도는 12개와 총 8 MiB입니다. 조회 원문과 연결·트랜잭션은 저장하지 않습니다. 그리드는 조회할 때 결과가 잘렸는지 표시합니다.

## 테이블 편집 검토 보관

테이블 그리드에서 변경을 검토한 뒤 **Save Table Edit Review**를 실행합니다. 워크스페이스에는 제안한 SQL과 매개변수 값, 원본 행의 지문이 남습니다. **Open Saved Table Edit Review**는 DB가 연결되지 않은 상태에서도 이 내용을 읽기 전용 문서로 엽니다.

같은 서버와 계정으로 연결하고 편집을 활성화한 뒤 원래 행이 있는 페이지를 엽니다. **Stage Saved Table Edit Review**가 현재 테이블 정의와 세션 설정을 확인하고, 편집 페이지와 별도 읽기 세션 양쪽에서 원본 행을 대조한 뒤 제안을 로컬 그리드에 올립니다. 그리드의 **Review**에서 새 검토를 생성합니다. **Apply**도 서버에서 행을 다시 확인하며 변경은 기존 **Commit** 흐름을 따릅니다. 워크스페이스에 최대 12개, 검토마다 1 MiB를 보관할 수 있습니다.
