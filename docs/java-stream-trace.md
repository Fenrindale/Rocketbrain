# Java Stream value trace

Open a trusted Java workspace with Rocketbrain's independent JDK configured. Select a complete Java stream expression through its terminal call. Run **Rocketbrain: Trace Java Stream Values** and confirm the run. The read-only trace shows the terminal result, the number of source values observed, the evaluation order, typed inputs and outputs, and an operation summary. Run **Rocketbrain: Go to Java Stream Stage** from the trace to jump to its original source range.

The trace runs the selected expression in a separate JVM with a memory ceiling, a timeout, cancellation, and a 512-event capture limit. The selection must be self-contained and sequential. Use literal `Stream.of` or `List.of(...).stream()`, JDK primitive stream factories, or bounded `IntStream` and `LongStream` ranges. The trace supports scalar expression lambdas and standard transformations such as filtering, mapping, flattening, boxing, distinct, natural sorting, and slicing. Terminal operations include lists, arrays, optional results, counts, primitive reductions, and match predicates. An imported class name requires JDT resolution to the corresponding JDK class. Fully qualified JDK names can be used directly.

The chronological rows come from the instrumented JDK pipeline. A short-circuiting terminal may request only part of the source. A stateful sort can consume the complete source before it emits its first result. A sized `count()` can return without evaluating any intermediate step. The trace reports when this occurred and distinguishes it from a capture that hit the event limit. Scalar values retain their runtime types and exact displayed long integer text. Lists and arrays report their terminal sizes while observed result values appear in the timeline. [Java SE 25 Stream API](https://docs.oracle.com/en/java/javase/25/docs/api/java.base/java/util/stream/Stream.html)

Project variables and classpath-dependent lambdas, arbitrary stream producers, parallel execution, and tracing a paused application are outside this workflow.
