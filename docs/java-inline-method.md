# Inline a Java Method Call

Place the cursor on a method name or select the full call in saved Java source in an imported project. Choose **Rocketbrain: Inline Java Method Call** from Code Actions or the Command Palette and review the diff. Applying the change updates one editor buffer, and a single Undo restores it.

The call must be the whole return expression or the whole initializer of one local variable. Choose an unqualified private static call, a private instance call on implicit or explicit `this`, or select the full call on a newly constructed instance of the same class. A receiver whose non-null value is uncertain requires keeping the original call. Use a same-class declaration with one return expression built from parameters, literals and supported Java operators. Instance methods can also read their direct, nonconstant primitive or `String` fields. Use primitive or `String` parameters and return types.

Generated typed locals evaluate a constructed receiver once before its arguments and each argument once in call order, including unused parameters. The copied expression reads the same fields on the selected receiver after argument evaluation. Javac checks the constructor, arguments, exact field bindings, selected overload's return conversion, inferred site type and whether a local would become a compile-time constant. The review applies to one selected invocation. Changes to the source or observed classpath require a new review. [Java invocation evaluation order](https://docs.oracle.com/javase/specs/jls/se25/html/jls-15.html#jls-15.12.4)
